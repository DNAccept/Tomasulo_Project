# docs/

Design documentation and paper-review supporting material.

## What goes here

- `architecture_diagram.png` (or .drawio/.svg source) — reservation stations,
  register-status table, CDB, and functional-unit layout. Draft this in Week 1
  before writing any code (Architecture Lead's task).
- `project_proposal.md` — the filled-in Part V §6 proposal template: team,
  assigned seed, chosen papers, problem statement, hardware/software config,
  planned innovation idea, anticipated risks, repo URL.
- `paper_notes/` — one notes file per reviewed paper, used to prep the
  10-slide paper-review presentation.

## Not here

Final presentation slides go in `presentation/`, not here. This folder is
working notes and diagrams, not deliverables.
