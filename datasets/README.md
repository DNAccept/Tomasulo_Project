# datasets/

## What goes here

The team's unique, seeded floating-point route-optimisation kernel,
generated by `student_implementation/gen_tomasulo_kernel.py` from
`configs/team_seed.json`.

This models a trotro network cost calculation: a mix of independent
distance computations (parallelisable) and a final weighted-sum reduction
(inherently sequential), engineered to have a known, team-specific ratio
of exploitable ILP.

## Rule

Don't hand-edit generated kernel files here — regenerate them from the
seed via the generator script so results stay reproducible.
