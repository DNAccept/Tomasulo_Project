# ai_use_declaration/

`ai_use_log.md` — one row per instance of AI use, updated weekly and
finalised at submission (Part V §8 template).

## Permitted uses

Clarifying a concept, explaining an error message, suggesting test cases,
improving documentation or grammar.

## Prohibited uses

Generating the complete project or a substantial unattributed portion,
submitting unexplained AI-generated code, fabricating results or
citations, bypassing required individual work.

See Part I §7 for the full integrity framework.
